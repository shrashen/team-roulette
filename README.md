# wheel-of-misfortune
This is a wheel of fortune style name picker that teams can use to randomize who gets picked to run the standup, retro or anything else. When someone's name comes up, there's a randomized highlighter that makes getting picked sound hilariously dreadful, which if true, hopefully makes it a little less so.

Use the Team Roster section to add or remove team member names from the wheel. 

Try it out https://shrashen.github.io/team-roulette/
